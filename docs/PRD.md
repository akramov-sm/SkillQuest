# SkillQuest — Product Requirements Document (PRD)

## 1. Видение
SkillQuest — персональная платформа саморазвития с механиками RPG. Реальные действия (код, учёба, спорт, чтение, финансы) превращаются в «миссии», за которые пользователь получает XP, повышает уровень, прокачивает дерево навыков и открывает достижения.

**Позиционирование:** «Linear для личного роста» — строгий, быстрый, красивый интерфейс + мотивационный слой игры.

## 2. Цели и задачи
| Цель | Метрика успеха |
|---|---|
| Сделать регулярные действия видимыми и приятными | Пользователь завершает ≥1 миссию в день |
| Дать ощущение прогресса | Уровень, XP-бар, уровни навыков всегда на виду |
| Удержание через streak и достижения | Серия активности, 11 достижений |
| Помочь анализировать развитие | Графики за неделю/месяц, распределение по категориям, история XP |
| Работать полностью локально | SQLite, без облака, без платных API |

**Не цели (v1):** многопользовательский режим, авторизация, синхронизация между устройствами, мобильное нативное приложение, push-уведомления.

## 3. Целевая аудитория
1. **Студенты и начинающие разработчики** — учат программирование/AI/английский, нужна дисциплина.
2. **Self-improvement энтузиасты** — ведут привычки (спорт, чтение, финансы), любят геймификацию.
3. **Профессионалы в переходе** — планомерно осваивают новый стек, нужна статистика прогресса.

Общее: технически грамотные, ценят минимализм, работают за ноутбуком и иногда с телефона.

## 4. Пользовательские сценарии
1. **Утро:** открываю Dashboard → вижу уровень, streak, задания на сегодня.
2. **Создание миссии:** «+ New mission» → название, категория, сложность (XP подставляется автоматически, можно изменить), срок.
3. **Выполнение:** отмечаю миссию → тост «+XP», при повышении уровня — модальное «Level up!», при открытии достижения — отдельный тост.
4. **Ошибся:** возвращаю миссию в работу (XP снимается) / редактирую / удаляю.
5. **Прокачка навыков:** Skill Tree показывает уровень и тиры каждого навыка; оттуда можно сразу создать миссию в навыке.
6. **Анализ:** Analytics — график активности (7/30 дней), доли категорий, прогресс навыков, лента XP.
7. **Профиль:** меняю имя/аватар, смотрю общую статистику, при желании сбрасываю прогресс.

## 5. Функциональные требования
### Dashboard
Уровень и общий XP; прогресс до следующего уровня; задания на сегодня (с быстрым выполнением и быстрым созданием); streak; статистика за неделю (XP, миссии, мини-график); последние достижения; срез по навыкам.

### Missions
CRUD; поля: название (обяз.), описание, категория (6 навыков), сложность (Easy/Medium/Hard/Epic), XP (1–1000), срок, статус (Active/Completed; Overdue вычисляется). Поиск, фильтры по статусу/категории, сортировка. Выполнить / вернуть в работу.

### Skill Tree
6 навыков: Programming, Artificial Intelligence, English, Fitness, Finance, Personal Development. У каждого: уровень, XP, прогресс до следующего уровня, 5 тиров (Novice → Master).

### Achievements
11 достижений (в т.ч. обязательные: первая миссия, 7 дней подряд, 10 миссий, 1000 XP, новый навык). Прогресс к цели, дата открытия, бонусный XP.

### Analytics
Активность за неделю/месяц; число выполненных заданий; распределение по категориям; прогресс навыков; история XP с подгрузкой.

### Profile
Имя, аватар (эмодзи + цвет), уровень, общий опыт, дата регистрации, статистика достижений; редактирование; сброс прогресса.

## 6. Нефункциональные требования
- Локальный запуск одной командой, данные переживают перезапуск.
- Адаптивность: 360px → 4K.
- Понятные ошибки, валидация на клиенте и сервере, состояния loading/empty/error.
- Доступность: фокус-кольца, контраст AA, `prefers-reduced-motion`.
- Нет внешних зависимостей (ни pip, ни CDN).

## 7. Допущения и решения
- Один локальный пользователь (id=1), без пароля.
- Удаление выполненной миссии **не** отнимает уже заработанный XP (история сохраняется); «вернуть в работу» — отнимает.
- Открытые достижения не отзываются.

## 8. Roadmap (после v1)
Повторяющиеся миссии, экспорт данных, теги, напоминания, облачная синхронизация, темы оформления.
